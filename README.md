## 🧠 What Is FACESEARCH.EXE?

FACESEARCH.EXE is a desktop visual intelligence pipeline that takes a face image, searches the live web for matching content, ranks discovered candidates using facial and visual similarity, and records the final result on a local EVM blockchain.

```text
📷 INPUT IMAGE
      ↓
🧠 FACENET512
      ↓
🌐 GOOGLE LENS / SERPAPI
      ↓
🔎 FACE + pHASH + TEXT RANKING
      ↓
🎯 BEST MATCH
      ↓
🔐 SHA-256 FINGERPRINT
      ↓
⛓️ GANACHE EVM
      ↓
✅ ON-CHAIN VERIFICATION
